# Design system — READ-ONLY reference

> **READ-ONLY.** This file documents the existing design system as found in the `:root` block and `<style>` of
> `cfo-workspace.html` (the `:root` block is identical in `cfo-overview.html`). Do not edit these values in code.
> Do not edit this file to "propose" changes. Reuse what is listed here.

## Fonts
- Body: `Inter, "Segoe UI", system-ui, -apple-system, sans-serif` — 14px / 20px, `--text-primary` on `--background`.
- Data: `.font-data` — `"JetBrains Mono"`, tabular numbers.

## Type scale
- `.t-h3` — 22/28, 600. Page title.
- `.t-h4` — 16/22, 700. Section/card title.
- `.t-h5` — 14/20, 600. Small heading.
- `.t-h6` — 12/16, 600, tracked. Overline heading.
- `.t-body-sm` — 13/18, 500. Compact body.
- `.t-caption` — 12/16, 400. Captions/meta.
- `.t-micro` — 10/12, 600, tracked. Micro labels.
- `.t-label` — 12/16, 600, `--text-secondary`. Form labels.
- `.c-heading` / `.c-secondary` / `.c-muted` — text color helpers.
- `.font-data` — monospace tabular numbers.
- `.sr-only` — visually hidden, screen-reader text.

## Buttons
- `.btn` — base button (36px high, 8px radius, 13px/600).
- `.btn-sm` — 32px-high size modifier.
- `.btn-primary` — primary gradient action (Summarize, Retry, Send).
- `.btn-secondary` — light gradient + border secondary action.
- `.btn-ghost` — transparent tertiary action.
- `.icon-btn` — 32px round icon-only button; `[aria-pressed="true"]` shows pressed state.
- `.icon-btn.md` — 36px icon button.
- `.icon-btn.menu-btn` — mobile nav toggle (shown < 1024px).
- `.pill` — rounded toggle (date presets); `[aria-pressed="true"]` = selected.
- `.chip` — suggested chat prompt.
- `.lang-btn`, `.user-btn` — topbar language and user menu buttons.
- `.kbd` — keyboard-shortcut hint inside a button.

## Controls
- `.field` — label + control column wrapper.
- `.ctl` — input/select/textarea base; `[aria-invalid="true"]` shows error border.
- `select.ctl` / `textarea.ctl` — select chevron / multi-line variants.
- `.search-wrap` — search input with leading icon.
- `.date-err` — inline date validation message.

## Cards & badges
- `.card` — white surface, border, 12px radius, xs shadow.
- `.sum-card` — highlighted summary header card.
- `.ai-tag` / `.ai-tag.mock` — "AI" label badge / neutral placeholder variant.
- `.icon-badge` (+ `.sm`, `.info`, `.success`, `.warning`, `.error`) — round tinted icon container.
- `.ai-mark` (+ `.sm`) — accent gradient AI avatar.
- `.agent-av` — agent initials avatar.

## Toast
- `.toasts` — fixed bottom-right container.
- `.toast` (+ `.info`, `.success`, `.error`) — notification; `.leaving` plays exit animation. Created only via `toast(msg, tone)`.

## Tabs
- `.tabstrip` — horizontal scrollable tab list (category tabs).
- `.tab` — tab button; `[aria-selected="true"]` = active (underline + tint).
- `.center-tabs` — Summary | Chart tabs, shown only < 1280px.

## Layout & panels (structure classes — do not restyle)
- `.sidebar`, `.sb-*`, `.topbar`, `.tb-*`, `.crumb`, `.content`, `.toolbar`, `.ws` (+ `.left-collapsed`, `.right-collapsed`, `.has-focus`), `.panel`, `.panel-head`, `.panel-body`, `.is-focused`.
- States: `.state`, `.gen-bar`, `.spinner`, `.sk` (skeleton).
- Summary: `.sec`, `.src`, `.meta`, `.actionbar`, `.feedback`, `.row-end`.
- Chat: `.thread`, `.msg.user`, `.msg.ai`, `.chat-wrap`, `.chips`, `.chat-form`.
- Chart: `.chart-tools`, `.chart-area`, `.chart-result`, `.canvas-wrap`, `.legend`.
- Dialog: `.dlg-head`, `.dlg-body`, `.dlg-foot`.

## Breakpoints (from CSS)
- `≤1599px` hide Summarize `.kbd` · `≤1439px` narrower controls/tabs · `≤1279px` right panel hidden, chart moves into center tab · `≤1023px` sidebar off-canvas · `≤767px` single column, full-width toolbar.

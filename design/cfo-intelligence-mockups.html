Investigate panel

Non-modal side sheet (560px at lg; full-width overlay below 1024). Header: item reference and title. Context line: domain, period, scope, origin. Body: evidence, cross-domain related signals, Q&A. Footer: suggested questions and the ask field.

Every answer shows its origin (⚙ / ✦) and is marked Verified, Partial or Not available. It opens from KPIs, signals, recommendations, table rows and agent findings. Opening moves focus to its heading; Esc or Close returns focus to the trigger. Only one panel at a time; opening another item replaces it, and pinning keeps the item on the Briefing.

Primary user journeys

Each step names the screen it happens on. Use the buttons to jump to that screen in the mockup.

CFO — morning briefing to decision (≈ 2 minutes)

  1. Opens CFO → Briefing. Scans six health tiles with deltas and origin labels.
  2. Reads "Since your last visit": 2 new high signals, 1 approval waiting.
  3. Opens the DSO movement → Investigate: evidence, formula, related Disputes and Collections signals.
  4. Goes to Decisions › Awaiting my approval → approves REC-0007 with a note. Recorded only; Execute stays disabled.

AR / Collections manager — overdue spike

  1. Signals, filtered to Receivables and Collections, New.
  2. Opens "Overdue 23.4%" → Domain › Receivables contributors table, sorted by share.
  3. Row action Investigate on Customer 022 → sees the R-PAY-01 payment-delay signal (z = 2.4).
  4. Accepts REC-0008 (prioritise outreach). The worklist change needs a connected collections service, so Execute is disabled with that reason.

Credit manager — exposure over limit

  1. Signal R-CR-01: Customer 014 at 104%.
  2. Investigate: exposure, open invoices, overdue share; payment-trend rule not run (insufficient history), shown explicitly.
  3. REC-0007 "Review credit limit" → Request approval. The system never changes a credit limit.

Cash application lead — unapplied cash

  1. Briefing or Signals: "Unapplied cash 6.1% (threshold 5%)".
  2. Domain › Cash App: unapplied % trend and a table of 23 receipts unapplied for more than 5 days (age, amount, customer).
  3. Exports the CSV; every row carries an origin column. Acknowledges the signal (audited).

Financial analyst — compare and outlook

  1. Domain › Receivables → Compare "vs Forecast": dashed forecast, scenario band, method caption.
  2. Opens the DSO formula popover: inputs, period, assumptions, provisional status.
  3. Changes context to Q4 2025 vs Q3 2025. All sections recalculate, and the URL is shareable.
  4. Exports the chart data with origin and method columns.
